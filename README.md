# Playwright AI Lab

An experimental project exploring AI-assisted test automation and AI-based evaluation of automated tests.

## What This Project Does

- Uses AI agents for test planning, test generation, and test healing.
- Automates web application testing using Playwright.
- Evaluates generated test cases using DeepEval.
- Uses LLM-as-a-Judge to assess scenario coverage and assertion quality.
- Combines AI evaluation with deterministic acceptance criteria.
